# PosPap — Masaüstü Kurulum Dosyaları

Bu depo yalnız **PosPap** masaüstü uygulamasının kurulum dosyalarını dağıtır; kaynak kod burada değildir.

**İndir:** <https://pospap.com> › *Uygulamayı edinin* — ya da doğrudan [son sürüm](../../releases/latest).

| Platform | Dosya |
|---|---|
| Windows 10 / 11 (64 bit) | `PosPap-Setup.exe` |
| macOS — Apple Silicon (M1 ve üzeri) | `PosPap-arm64.dmg` |

Her zaman en güncel sürüm:

- Windows: <https://pospap.com/indir/windows>
- macOS: <https://pospap.com/indir/mac>

## İlk açılış

- **Windows:** "Windows bilgisayarınızı korudu" uyarısı çıkarsa **Ek bilgi → Yine de çalıştır**.
- **macOS:** DMG'yi açıp PosPap'ı *Uygulamalar* klasörüne sürükleyin. İlk açılışta "doğrulanamadı"
  uyarısı çıkarsa **Sistem Ayarları → Gizlilik ve Güvenlik → Yine de Aç**.
